# پاسخ جامع: جریان مبلغ برگشتی در سیستم بودجه

## سوال اصلی
> سیستم الان تو برگشت از بودجه به بودجه کلان یک ردیف اضافه میکنه و اون مقدار برگشت خورده رو کجا بر میگردونه ؟ که بشه به سیستم مجدد اختصاص داد ؟

## پاسخ کامل

### 🔍 تحلیل جریان مبلغ برگشتی

بر اساس تست‌های انجام شده، جریان مبلغ برگشتی در سیستم به شرح زیر است:

#### 1️⃣ هنگام برگشت بودجه چه اتفاقی می‌افتد؟

```python
# در مدل BudgetTransaction.save()
if self.transaction_type == 'RETURN':
    # کاهش مبلغ تخصیص‌یافته
    self.allocation.allocated_amount -= self.amount
    
    # افزایش مبلغ برگشتی در تخصیص
    self.allocation.returned_amount += self.amount
    
    # افزایش مبلغ برگشتی در دوره بودجه کلان
    budget_period.returned_amount += self.amount
```

#### 2️⃣ مبلغ برگشتی کجا ذخیره می‌شود؟

**در دو مکان:**
- **BudgetAllocation.returned_amount**: مبلغ برگشتی از این تخصیص خاص
- **BudgetPeriod.returned_amount**: مجموع تمام مبالغ برگشتی در دوره بودجه کلان

#### 3️⃣ چگونه مبلغ برگشتی قابل تخصیص مجدد است؟

**فرمول محاسبه مانده دوره بودجه:**
```
مانده = مبلغ_کل - مجموع_تخصیص‌ها + مجموع_برگشتی
```

**مثال عملی:**
- مبلغ کل دوره: 800,000,000 ریال
- مجموع تخصیص‌ها: 189,380,000 ریال  
- مجموع برگشتی: 10,310,000 ریال
- **مانده قابل تخصیص: 620,930,000 ریال**

### ✅ نتیجه‌گیری

#### مبلغ برگشتی:
1. **از تخصیص کم می‌شود** ✅
2. **به فیلد returned_amount اضافه می‌شود** ✅
3. **در محاسبه مانده دوره بودجه لحاظ می‌شود** ✅
4. **قابل تخصیص مجدد است** ✅

#### مزایای این روش:
- **شفافیت کامل**: تمام مبالغ برگشتی قابل ردیابی هستند
- **قابلیت تخصیص مجدد**: مبلغ برگشتی در محاسبه مانده لحاظ می‌شود
- **تاریخچه کامل**: تمام عملیات در BudgetHistory ثبت می‌شوند
- **کنترل دقیق**: امکان بررسی جزئیات هر برگشت

### 📊 مثال عملی از تست

#### وضعیت قبل از برگشت:
- دوره بودجه کل: 800,000,000 ریال
- مجموع تخصیص‌ها: 200,000,000 ریال
- مجموع برگشتی: 1,000,000 ریال

#### بعد از برگشت 4,900,000 ریال:

- مجموع برگشتی: 5,900,000 ریال (افزایش یافت)
- **مانده قابل تخصیص: 605,900,000 ریال**

#### بعد از تخصیص مجدد 10,000,000 ریال:
- دوره بودجه کل: 800,000,000 ریال
- مجموع تخصیص‌ها: 189,380,000 ریال
- مجموع برگشتی: 10,310,000 ریال
- **مانده قابل تخصیص: 620,930,000 ریال**

### 🔧 نحوه استفاده از مبلغ برگشتی

#### برای تخصیص مجدد:
1. **محاسبه مانده**: استفاده از `budget_period.get_remaining_amount()`
2. **ایجاد تخصیص جدید**: استفاده از مبلغ برگشتی در محاسبه مانده
3. **ثبت تاریخچه**: ثبت عملیات در BudgetHistory

#### کد نمونه:
```python
# محاسبه مانده قابل تخصیص
available_amount = budget_period.get_remaining_amount()

# ایجاد تخصیص جدید
new_allocation = BudgetAllocation.objects.create(
    budget_period=budget_period,
    organization=organization,
    budget_item=budget_item,
    project=project,
    allocated_amount=new_amount,  # از مبلغ برگشتی استفاده می‌شود
    # ...
)
```
