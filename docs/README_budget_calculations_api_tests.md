3. **`api_project_calculations.py`** - محاسبات بودجه پروژه
4. **`api_subproject_calculations.py`** - محاسبات بودجه زیرپروژه

7. **`api_utility_calculations.py`** - توابع کمکی محاسبات
8. **`api_batch_calculations.py`** - محاسبات دسته‌ای

## نتایج مورد انتظار

### ✅ تست‌های موفق

- **نمای کلی API ها:** دریافت لیست توابع و URL ها
- **محاسبات تخصیص:** محاسبه بودجه باقی‌مانده
- **محاسبات سازمان:** محاسبه بودجه کل، بودجه و باقی‌مانده
- **محاسبات پروژه:** محاسبه بودجه کل، مصرف‌شده و باقی‌مانده
- **محاسبات زیرپروژه:** محاسبه بودجه کل، مصرف‌شده و باقی‌مانده
- **محاسبات تنخواه:** محاسبه بودجه کل، باقی‌مانده، در تعهد، مصرف‌شده و در دسترس
- **محاسبات فاکتور:** محاسبه بودجه کل، مصرف‌شده و باقی‌مانده
- **توابع کمکی:** اجرای توابع کمکی مختلف
- **محاسبات دسته‌ای:** اجرای چندین محاسبه همزمان

### ❌ تست‌های ناموفق احتمالی

- **خطای احراز هویت:** اگر کاربر وارد نشده باشد
- **خطای شناسه نامعتبر:** اگر ID موجودیت وجود نداشته باشد
- **خطای پارامترهای مفقود:** اگر پارامترهای الزامی ارسال نشده باشد
- **خطای نوع محاسبه نامعتبر:** اگر نوع محاسبه صحیح نباشد

## عیب‌یابی

### مشکلات رایج

#### 1. خطای احراز هویت
```
❌ احراز هویت: خطا - 401
```

**راه‌حل:**
- اطمینان حاصل کنید که کاربر وارد شده است
- بررسی کنید که `self.client.force_authenticate(user=self.user)` اجرا شده باشد

#### 2. خطای مدل‌ها
```
❌ محاسبات بودجه سازمان: خطا - ModuleNotFoundError
```

**راه‌حل:**
- اطمینان حاصل کنید که Django تنظیم شده است
- بررسی کنید که مدل‌ها در `budgets.models` و `core.models` موجود هستند

#### 3. خطای URL ها
```
❌ نمای کلی API ها: خطا - NoReverseMatch
```

**راه‌حل:**
- بررسی کنید که URL ها در `budgets/urls.py` تعریف شده باشند
- اطمینان حاصل کنید که نام‌های URL صحیح هستند

#### 4. خطای Mock ها
```
❌ محاسبات بودجه پروژه: خطا - AttributeError
```

**راه‌حل:**
- بررسی کنید که Mock ها به درستی تنظیم شده باشند
- اطمینان حاصل کنید که نام‌های توابع Mock صحیح هستند

### بررسی لاگ‌ها

برای بررسی جزئیات خطاها، لاگ‌های Django را بررسی کنید:

```bash
# اجرای سرور با لاگ‌های تفصیلی
python manage.py runserver --verbosity=2

# بررسی لاگ‌های تست
python manage.py test tests.test_budget_calculations_api --verbosity=2
```

### تست دستی API ها

برای تست دستی API ها، می‌توانید از curl یا Postman استفاده کنید:

```bash
# تست نمای کلی API ها
curl -H "Authorization: Bearer YOUR_TOKEN" \
     http://localhost:8000/budgets/api/calculations/

# تست محاسبه مبلغ بر اساس درصد
curl -H "Authorization: Bearer YOUR_TOKEN" \
     "http://localhost:8000/budgets/api/calculations/allocation/?base_amount=1000000&percentage=10"
```
