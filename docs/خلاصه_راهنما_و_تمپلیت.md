## ویژگی‌های کلیدی

### ✅ راهنمای جامع
- **مستندات کامل**: تمام جنبه‌های سیستم پوشش داده شده
- **نمونه کد**: کدهای عملی برای هر بخش
- **نمودارها**: نمایش روابط و فرآیندها
- **عیب‌یابی**: راه‌حل مشکلات رایج

### ✅ آمار زنده
- **آمار دوره‌های بودجه**: تعداد فعال، تمام‌شده
- **آمار تخصیص‌ها**: تعداد فعال، قفل‌شده
- **آمار تراکنش‌ها**: تعداد برگشت، مصرف
- **آمار مبالغ**: مجموع تخصیص، برگشت، مصرف

### ✅ طراحی مدرن
- **رابط کاربری زیبا**: طراحی مدرن و کاربرپسند
- **انیمیشن‌ها**: تعاملات نرم و جذاب
- **واکنش‌گرا**: سازگار با تمام دستگاه‌ها
- **رنگ‌بندی مناسب**: استفاده از رنگ‌های مناسب

### ✅ عملکرد بهینه
- **کش**: استفاده از کش برای بهبود عملکرد
- **به‌روزرسانی خودکار**: آمار هر 30 ثانیه به‌روزرسانی می‌شود
- **بارگذاری سریع**: بهینه‌سازی تصاویر و فایل‌ها
- **کد تمیز**: کدهای بهینه و قابل نگهداری

## نحوه استفاده

### 1. دسترسی به راهنما
```
http://localhost:8000/budgets/guide/
```

### 2. دسترسی به آمار
```
http://localhost:8000/budgets/stats/
```

### 3. از داشبورد بودجه
- روی کارت "راهنمای سیستم" کلیک کنید
- لینک‌های "مطالعه راهنما" و "آمار سیستم" را انتخاب کنید

## تست‌ها و اعتبارسنجی

### ✅ تست‌های موجود
- `test_budget_return_model_only.py` - تست ساده برگشت بودجه
- `test_budget_return_comprehensive.py` - تست جامع برگشت بودجه  
- `analyze_budget_return_flow.py` - تحلیل جریان مبلغ برگشتی
- `test_reallocate_returned_budget.py` - تست تخصیص مجدد مبلغ برگشتی

### ✅ نتایج تست‌ها
همه تست‌ها با موفقیت اجرا شده‌اند و نشان می‌دهند که:
- سیستم برگشت بودجه به درستی کار می‌کند
- مبلغ برگشتی در محاسبه مانده لحاظ می‌شود
- امکان تخصیص مجدد مبلغ برگشتی وجود دارد
- تمام عملیات در تاریخچه ثبت می‌شوند

## API های موجود

### 1. دریافت مانده آزاد
```
GET /api/budget/allocation/{id}/free-budget/
```

### 2. لیست تخصیص‌ها
```
GET /api/budget/allocations/?search=پروژه&page=1
```

### 3. ثبت برگشت بودجه
```
POST /api/budget/return/
```

### 4. لیست تراکنش‌ها
```
GET /api/budget/transactions/
```
