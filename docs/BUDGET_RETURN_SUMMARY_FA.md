# خلاصه برگشت بودجه - پاسخ به سوال شما

## سوال: چطور بودجه را از بودجه دوره (id=30) به کلان بودجه برگردانیم؟

### پاسخ کوتاه:

سیستم شما **از قبل** قابلیت برگشت بودجه را دارد. وقتی بودجه را از یک **BudgetAllocation** (تخصیص بودجه به پروژه) برگشت می‌دهید، به‌صورت خودکار به **BudgetPeriod** (کلان بودجه) برمی‌گردد.

## نحوه استفاده

### روش 1: از صفحه جزئیات کلان بودجه (BudgetPeriod)

1. به صفحه جزئیات کلان بودجه بروید:

   ```
   http://127.0.0.1:8000/budgets/budgetperiod/30/
   ```

2. در جدول "تخصیص‌های بودجه" موارد زیر را می‌بینید:

   - مبلغ تخصیص
   - باقی‌مانده (available)
   - مبلغ برگشتی
   - دکمه "برگشت بودجه" (برای تخصیص‌هایی که باقی‌مانده > 0)

3. روی دکمه "برگشت بودجه" کلیک کنید

4. فرم برگشت را پر کنید:

   - مبلغ برگشتی
   - دلیل برگشت
   - توضیحات

5. سیستم به‌صورت خودکار:
   - موجودی child را کاهش می‌دهد
   - موجودی parent را افزایش می‌دهد
   - تراکنش RETURN ثبت می‌کند
   - تاریخچه را ثبت می‌کند

### روش 2: از صفحه جزئیات تخصیص بودجه

1. از صفحه کلان بودجه، روی دکمه "جزئیات" (آیکون چشم) کلیک کنید
2. در صفحه جزئیات تخصیص بودجه، دکمه "برگشت بودجه" را بزنید

## نمایش در کلان بودجه

پس از برگشت، در صفحه جزئیات کلان بودجه (`/budgets/budgetperiod/30/`) موارد زیر نمایش داده می‌شود:

### 1. خلاصه وضعیت بودجه (4 کارت):

- **بودجه کل**: کل مبلغ بودجه
- **تخصیص یافته**: مجموع تخصیص‌ها به پروژه‌ها
- **مجموع برگشتی از زیرمجموعه‌ها**: کل مبالغ برگشتی
- **موجودی کلان بودجه**: `بودجه کل - تخصیص + برگشتی`

### 2. جدول تخصیص‌های بودجه:

برای هر تخصیص نمایش داده می‌شود:

- مبلغ تخصیص
- باقی‌مانده
- مبلغ برگشتی
- دکمه "برگشت بودجه" (اگر باقی‌مانده > 0 باشد)

### 3. جدول برگشت‌ها:

- تاریخ برگشت
- مبلغ برگشتی
- تخصیص مرتبط
- توضیحات

## نحوه محاسبه موجودی

### برای کلان بودجه (BudgetPeriod):

```python
available = total_amount - total_allocated + returned_amount
```

**مثال:**

- بودجه کل: 1,000,000
- تخصیص یافته: 800,000
- برگشتی: 30,000
- **موجودی = 1,000,000 - 800,000 + 30,000 = 230,000**

### برای تخصیص بودجه (BudgetAllocation):

```python
available = allocated_amount - consumed + returned
```

## مثال عددی کامل

**قبل از برگشت:**

کلان بودجه (id=30):

- بودجه کل: 1,000,000
- تخصیص یافته: 800,000
- برگشتی: 0
- موجودی: 200,000

تخصیص بودجه (id=50):

- تخصیص: 200,000
- مصرف: 150,000
- برگشتی: 0
- باقی‌مانده: 50,000

**عملیات برگشت 30,000:**

سیستم انجام می‌دهد:

1. کاهش `allocated_amount` در تخصیص: 200,000 → 170,000
2. افزایش `returned_amount` در تخصیص: 0 → 30,000
3. کاهش `total_allocated` در کلان بودجه: 800,000 → 770,000
4. افزایش `returned_amount` در کلان بودجه: 0 → 30,000
5. ثبت تراکنش RETURN با مبلغ 30,000

**بعد از برگشت:**

کلان بودجه (id=30):

- بودجه کل: 1,000,000
- تخصیص یافته: 770,000
- برگشتی: 30,000
- **موجودی: 260,000** ✅ (200,000 + 30,000)

تخصیص بودجه (id=50):

- تخصیص: 170,000
- مصرف: 150,000
- برگشتی: 30,000
- باقی‌مانده: 50,000 ✅ (همان مقدار قبل)
