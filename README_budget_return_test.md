# تست جامع سیستم برگشت بودجه از تنخواه

## توضیحات

این مجموعه تست‌ها برای بررسی عملکرد سیستم برگشت بودجه از تنخواه طراحی شده است. تست‌ها شامل موارد زیر می‌باشند:

### تست‌های اصلی

1. **تست برگشت بودجه از تنخواه**
   - ثبت تراکنش برگشت
   - به‌روزرسانی مانده تنخواه
   - به‌روزرسانی مانده تخصیص بودجه
   - به‌روزرسانی مانده دوره بودجه کلان
   - ثبت در تاریخچه بودجه

2. **تست چندین برگشت بودجه متوالی**
   - ثبت چندین تراکنش برگشت
   - محاسبه صحیح مجموع برگشتی
   - به‌روزرسانی صحیح مبالغ در تمام سطوح

3. **تست اعتبارسنجی**
   - جلوگیری از برگشت مبلغ بیش از مانده تنخواه
   - جلوگیری از برگشت مبلغ منفی
   - اعتبارسنجی صحیح ورودی‌ها

## فایل‌های تست

- `test_budget_return_comprehensive.py`: کلاس تست اصلی
- `run_budget_return_test.py`: اسکریپت اجرای تست
- `budget_return_test_report.md`: گزارش نتایج تست
- `budget_return_test.log`: لاگ کامل اجرای تست

## نحوه اجرا

### روش 1: اجرای دستی
```bash
python run_budget_return_test.py
```

### روش 2: اجرای با Django Test Runner
```bash
python run_budget_return_test.py --django
```

### روش 3: اجرای مستقیم تست
```bash
python test_budget_return_comprehensive.py
```

## داده‌های تست

تست با داده‌های زیر اجرا می‌شود:

- **دوره بودجه**: 1 میلیارد ریال
- **تخصیص بودجه**: 500 میلیون ریال
- **تنخواه**: 200 میلیون ریال
- **مبلغ برگشتی**: 50 میلیون ریال

## بررسی‌های انجام شده

### سطح تنخواه
- مانده تنخواه بعد از برگشت
- اعتبارسنجی مبلغ برگشتی

### سطح تخصیص بودجه
- مانده تخصیص بعد از برگشت
- مبلغ برگشتی ثبت شده
- وضعیت تخصیص

### سطح پروژه
- مانده پروژه
- محاسبات مربوط به پروژه

### سطح دوره بودجه کلان
- مانده کل دوره بودجه
- مجموع مبالغ برگشتی
- وضعیت قفل دوره بودجه

## نکات مهم

1. **قبل از اجرا**: اطمینان حاصل کنید که Django به درستی تنظیم شده است
2. **داده‌های تست**: تست‌ها داده‌های موقت ایجاد می‌کنند و در پایان پاک می‌شوند
3. **لاگ‌ها**: تمام عملیات در فایل لاگ ثبت می‌شوند
4. **گزارش**: گزارش نهایی در فایل Markdown ذخیره می‌شود

## عیب‌یابی

### خطاهای رایج

1. **خطای Django Settings**
   ```
   django.core.exceptions.ImproperlyConfigured
   ```
   **راه حل**: تنظیم متغیر محیطی `DJANGO_SETTINGS_MODULE`

2. **خطای دسترسی به دیتابیس**
   ```
   django.db.utils.OperationalError
   ```
   **راه حل**: بررسی تنظیمات دیتابیس در settings.py

3. **خطای مدل‌ها**
   ```
   django.core.exceptions.FieldError
   ```
   **راه حل**: بررسی وجود مدل‌ها و فیلدهای مورد نیاز

### بررسی لاگ‌ها

برای بررسی جزئیات خطاها، فایل `budget_return_test.log` را مطالعه کنید.

## توسعه تست

برای اضافه کردن تست‌های جدید:

1. متد جدید در کلاس `BudgetReturnComprehensiveTest` اضافه کنید
2. نام متد را با `test_` شروع کنید
3. در تابع `main()` فراخوانی کنید

## مثال استفاده

```python
# اجرای تست خاص
test_instance = BudgetReturnComprehensiveTest()
test_instance.setUp()
test_instance.test_budget_return_from_tankhah()
test_instance.tearDown()
```
