# Docker Secrets Directory

این دایرکتوری برای نگهداری امن مقادیر حساس (مانند رمز دیتابیس و کلید جنگو) استفاده می‌شود. فایل‌های متنی داخل این پوشه در `.gitignore` قرار دارند و هرگز نباید در مخزن ذخیره شوند.

## فایل‌های مورد نیاز

- `db_password.txt` – رمز دیتابیس (MySQL/PostgreSQL)
- `redis_password.txt` – رمز Redis
- `django_secret_key.txt` – مقدار `SECRET_KEY` جنگو

## نحوه ایجاد

برای راحتی می‌توانید اسکریپت `docker-scripts/setup-secrets.ps1` را اجرا کنید تا فایل‌ها به صورت ایمن ایجاد یا به‌روزرسانی شوند:

```powershell
cd docker-scripts
.\setup-secrets.ps1
```

این اسکریپت از شما مقادیر را می‌پرسد (یا مقادیر موجود را بازاستفاده می‌کند) و آن‌ها را فقط در این پوشه ذخیره می‌کند.

> **هشدار:** هرگز این فایل‌ها را در مخزن گیت کامیت نکنید. در صورت نیاز برای انتقال، فقط محتوا را به محیط مقصد منتقل کنید.
