# Change: Add VAT settings with toggle and audited updates

## Why
- VAT نرخ و فعال/غیرفعال بودن باید یکجا در تنظیمات سیستم قابل مدیریت باشد.
- هر تغییر باید با نام کاربری و مقدارهای قبل/بعد ثبت و قابل مشاهده باشد.
- محاسبه فاکتور در کل سیستم باید از تنظیمات سیستم تبعیت کند (فعال/غیرفعال + درصد).

## What Changes
- افزودن قابلیت «تنظیمات VAT» در صفحه `system-settings` با فیلدهای نرخ و وضعیت فعال‌سازی.
- ثبت لاگ تغییرات VAT شامل کاربر، زمان، مقدارهای قبل/بعد و نمایش آن در UI تنظیمات.
- استفاده از تنظیمات VAT در محاسبه فاکتور (کل سیستم/فرانت) فقط وقتی VAT فعال است.

## Impact
- Affected specs: system-settings (جدید)
- Affected code: تنظیمات سیستم، مدل/سرویس VAT، محاسبه فاکتور و UI محاسبه.
